# ЭТАП 1 — Функциональная планировочная схема банного SPA-комплекса

## 1. Проверка исходной геометрии (20.00 × 15.00 м, зал 13 × 15)

| Параметр | Требование | Факт (со стенами 300/200) | Статус |
|---|---|---|---|
| Чистый зал | — | 12.50 × 14.40 м | — |
| Торцевые проходы | ≥ 1.50 м | 1.25 / 1.25 м | ✗ ОШИБКА |
| Боковые проходы | ≥ 2.50 м | 2.20 / 2.20 м | ✗ ОШИБКА |

Боковые 2.50 м требуют чистой глубины 15.00 м (10+2.5+2.5), всё здание даёт 14.40 м
⇒ **требование невыполнимо в глубине 15.0 м ни при какой планировке.**
Ориентация «боковые по ширине 20 м» требует зал 15.5 м осевых → сервисный блок 4.5 м,
программа ~80 м² туда не помещается (доступно 57.6 м²). См. `conflict_20x15.svg`.

**Бюджет согласованной схемы: зал 210.6 + банный блок ~95 + лаунж ~29 + тех ~27 ≈ 356 м²**

### Предложенная корректировка геометрии (к утверждению)

**Глубина 15.00 → 17.80 м (ширина 20.00 м без изменений), площадь 356.0 м² (+18.7%).**
Альтернативы (не разрабатывались): сохранить 300 м², сократив состав помещений/удалив лаунж;
уменьшить бассейн — запрещено ТЗ.

## 3. Ведомость дверей

| Дверь | Откуда → куда | Ширина, мм | Открывание |
|---|---|---|---|
| D1 | Улица (зап. фасад) → Тамбур | 1200 | внутрь — **главный вход** |
| D2 | Тамбур → Холл | 900 | в холл |
| D3 | Холл → Раздевалка | 1000 | в раздевалку |
| D4 | Раздевалка → Санузел | 800 | в санузел (минуя душевую) |
| D5 | Раздевалка → Душевые | 800 | в душевую |
| D6 | Душевые → Русская парная | 800 | из парной (наружу, безопасность) |
| D8 | Душевые → Финская сауна | 800 | из сауны (наружу) |
| D7 | Душевые → Хамам | 800 | из хамама (наружу) |
| D9 | Душевые → Бассейновый зал | 800 | в зал |
| D10 | Улица (сев. фасад) → Инженерная | 1000 | внутрь — **технический вход** |
| D11 | Инженерная → Насосная | 800 | служебная (на замке) |
| D12 | Насосная → Зал | 800 | служебная, обслуживание (на замке) |

Все проёмы вырезаны в теле стен (см. план): стены начерчены сегментами,
двери не «поверх стены». Проверка Б подтверждает: каждая дверь связывает
два реальных помещения, дверей «в стену» нет, пересечений проёмов нет.

## 5. Проверка доступности (сводно, по графу дверей)

- Все 11 помещений достижимы от главного входа (BFS) — **OK**.
- Санузел доступен из раздевалки БЕЗ прохода через душевую — **OK**.
- Бани примыкают к душевой, вход в бани НЕ через бассейновый зал — **OK**.
- Нет помещений «без двери» или «только через техническую зону» — **OK**.
- Техперсонал: улица → инженерная → насосная → (зал) без захода в
  посетительские помещения — **OK**.
- Посетительский и технический потоки пересекаются только в зале
  (дверь D12 служебная, на замке).

## 6. Принятые решения и логика

1. **Геометрия:** глубину 15.0 → 17.8 м — единственное изменение; ширина 20.0 сохранена.
2. **Зал** 13.10×17.20 чистыми: бассейн по центру, боковые 2.50 (юг/север),
   торцевые 1.55 (запад/восток) — требования выполнены с запасом 50 мм.
3. **Банный блок** (6.5 м осевых) — линейная последовательность юг→север:
   тамбур → холл → раздевалка → душевые → банный ряд / выход в зал (D9).
4. **Душевая — планировочный узел:** из неё двери во все три бани и в зал;
   бани «глухие» (не проходные), двери бань открываются наружу.
5. **Зона отдыха** — открытая полоса 13.10×2.20 м (28.82 м²) у северного
   остекления над северной дорожкой: вид на воду через дорожку, проходы
   не перекрываются, мебель у стены.
6. **Техблок** на севере блока (насосная 12.76 + инженерная 13.64 м²)
   с отдельным северным входом D10; насосная смежна с залом (D12 для
   обслуживания, короткие трассы к чаше).

## 7. Открытый вопрос к утверждению

Исходные 300 м² (20×15) **математически не вмещают** программу при
требуемых проходах бассейна (см. разд. 1). Варианты:

- **А (реализован в СХ-1): 20.00 × 17.80 м = 356.0 м²** — всё ТЗ выполнено.
- Б — сохранить 300 м²: сократить состав (например, убрать отдельное
  техпомещение/лаунж или совместить сауну с хамамом) + принять проходы
  у бассейна 2.20/1.25 м (нарушение ваших же требований). Не рекомендуется.
- В — изменить пропорцию: 22.0 × 15.6 м (343 м²) — зал шире, блок 6.5 м,
  лаунж у восточного торца; полный пересмотр схемы.
